Propósito de la Asignatura

La asignatura de Ingeniería Web aborda los principios fundamentales del desarrollo cliente-servidor, protocolos de comunicación HTTP y construcción de arquitecturas web robustas.

En este proyecto se explora cómo procesar rutas y recursos como CSS y HTML utilizando el módulo nativo http y fs de Node.js.
